# Outbound allowlist for the AI agents sandbox.
#
# One hostname per line. Comments (#) and blank lines are ignored.
# Read at container start by init-firewall.sh; everything not listed here (and
# not in the GitHub ranges it fetches) is rejected.
#
# THIS FILE IS BAKED INTO THE IMAGE at build time (Dockerfile -> COPY). Editing
# it does NOTHING to a container that is already built. To apply an edit:
#     F1 -> Dev Containers: Rebuild Container      (or: agent.sh rebuild)
#
# To unblock a host right now, without a rebuild, from inside the container:
#     EXTRA_ALLOWED_DOMAINS="a.example.com b.example.com" \
#       sudo /usr/local/bin/init-firewall.sh
# That lasts until the container restarts.
#
# Note: entries are resolved to IPs at apply time. If a host that used to work
# starts failing, its IPs rotated - re-run init-firewall.sh.
